## 适用场景

目标窗口是 macOS 或 Windows 的系统计算器，任务是算出一个数值结果。

## 脚本

- 本技能目录下的脚本（如果有）会随技能注册成工具；具体有哪些、各自适用什么画面，以系统提示的「脚本」一节为准。
- 任务和某个脚本的适用条件一致时，优先调用脚本，不要按下面的步骤手动重做一遍。
- 脚本失败会说明停在第几步，按当时的新截图和下面的步骤接手；没有可用脚本时，按下面的步骤手动操作。

## 操作步骤

1. 先看当前截图，确认显示区和按键区都完整可见；看不到就在说明里讲清楚，不要自己去找应用或切换窗口。
2. 点一次「AC」或「C」把显示区清空，确保从 0 开始。
3. 按算式从左到右逐个点击按键，顺序是「数字 → 运算符 → 数字」。每点一个键，都等下一张截图确认显示区已经变化，再点下一个。
4. 点「=」之后读显示区的数字，和你在心里算出的结果核对。
5. 一致才宣布完成，说明里写出「算式 = 结果」；不一致就点「AC」重来一次，第二次仍然不一致就停下来说明卡在哪一步。

## 注意

- 按钮很小，坐标取按钮的视觉中心；宁可多看一眼截图，也不要凭记忆连点。
- 系统计算器常常不接受剪贴板粘贴，输入数字用点击，不要用 type。
- 减号是「−」键，乘除是「×」「÷」键，不要用键盘符号代替。
- 小数点在计算器上是「.」键，正负号用「+/-」。
- 按错一个键就整体重来，不要在错误的中间结果上继续算。
