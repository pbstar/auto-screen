# Auto Screen

可视化桌面操作 Agent：选一个窗口，输入一句任务，它循环「截图 → 视觉模型决策 → 鼠标/键盘动作 → 再截图」，把事做完。全过程可视，可暂停、可接管。

技术方案见 [docs/技术方案.md](docs/技术方案.md)，开发约定见 [CLAUDE.md](CLAUDE.md)。

## 开发

```bash
npm install
npm run dev
```

```bash
npm run typecheck
npm run build
```

## 配置

在应用里点任务卡右上角的「⋮ → 配置模型」，填写接口地址、模型 ID 和 API Key，保存后立即生效，不用重启。

配置只保存在本机 `userData/model.json`（macOS 为 `~/Library/Application Support/auto-screen/model.json`，文件权限 0600），不随仓库走；Key 不会回显、不会写进日志。没填 Key 时界面会提示，且不会启动 Agent。

## 系统权限

- macOS：需要「屏幕录制」「辅助功能」，以及「自动化」中允许控制 System Events（用于把目标窗口激活到最前），授权后重启应用。
- Windows：目标窗口以管理员权限运行时，本应用也需要以管理员身份启动。

## 当前能力

- 顶栏下拉选择目标窗口，预览区实时显示画面，叠加 10px 刻度与虚线主格，悬停读坐标
- 发给模型的截图叠加同一套网格（长边缩放到 1280，样式与预览共用一份常量），上一次指针动作的落点用青色小十字标出
- Agent 每步只做一个动作，最多 300 步；输入优先走键盘
- 开始前先由模型定一份 3~8 步的流程与完成标准，执行步带着流程办事、不再重复推演；模型宣布完成后还要按任务要求核对结果，不通过会自动返工一次，仍未通过则以「未通过核对」结束，且不生成技能
- 等待：支持最长 1 小时的固定等待、「等画面变化」（本机轮询，不消耗模型调用）与「等到某个时刻」，等待中可暂停、可终止，时间线显示进度
- 技能：`skills/<id>/SKILL.md` 写操作手册，点任务输入框下方的「技能」胶囊勾选后注入系统提示（示例见 `skills/calculator/`）
- 安全底线：操作范围、不可撤销动作、验证与凭据、如实汇报四条边界写死在系统提示里，始终生效、不可关闭；想给某类任务追加约束就写进技能手册
- 自动沉淀技能：任务卡上的「自动沉淀」开关（默认关闭）打开后，任务自然完成时把这次的操作流程整理成 `skills/<slug>/SKILL.md`（英文目录名、界面显示中文名，重名加序号）；只写通用流程、不写本次的具体数据，不会覆盖已有技能，也不自动勾选，在「技能」里勾选即可下次复用
- 任务中途可以向你提问：遇到歧义或不可撤销操作时，Agent 在右侧弹出选项卡片，回答后继续，也可以跳过
- 运行中可暂停、继续、终止；检测到你在动鼠标会自动暂停，把控制权让给你
- 每次运行在 `runs/<时间>/` 下落一份文本日志与每步截图，界面「日志」可查看历史运行
