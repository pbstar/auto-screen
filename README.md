# Auto Screen

可视化桌面操作 Agent。当前进度：**M1 手动操作台**。

设计方案见 [docs/技术方案.md](docs/技术方案.md)。

## 开发

```bash
npm install
npm run dev
```

## 静态检查

```bash
npm run typecheck
npm run build
```

## 系统权限

- macOS：需要「屏幕录制」和「辅助功能」权限，授权后重启应用。
- Windows：目标窗口以管理员权限运行时，本应用也需要以管理员身份启动。

## 当前功能（M1）

- 枚举并选择目标窗口，按窗口截屏
- 预览区显示 10px 刻度标尺、100px 虚线网格，坐标按 10px 取整
- 悬停读坐标、取点模式点击复制坐标
- 单击 / 双击 / 右键、剪贴板文本输入、组合键发送
- 鼠标坐标单位自动判断，可手动切换（点击整体偏移时使用）
